# Kafé Kardemumma

En liten webbplats för det påhittade caféet Kafé Kardemumma, byggd som övning i Lexicons Modul 4 (UI/UX & Frontend). Sidan har en startsida med meny och "om oss", samt ett bokningsformulär.

**Live-sida:** https://fungusflip.github.io/m4-dag10-github-och-publicering/

## Tekniker

- HTML5 med semantiska element (header, nav, main, section, article, footer)
- Tillgängligt formulär med label, fieldset och legend
- CSS uppdelad i fyra filer: variabler, bas, layout och komponenter
- CSS-variabler för färger, typsnitt och avstånd
- Flexbox och CSS Grid för layout
- Responsiv design med mobile first och media queries
- Git och GitHub, publicerad med GitHub Pages
